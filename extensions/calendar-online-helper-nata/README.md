# Calendar.online Helper — Ната

Розширення для Chrome / Edge — швидке додавання задач для **Наталії** у Calendar.online **на весь день**.

## Встановлення

1. Завантажте `calendar-online-helper-nata.zip`
2. Розпакуйте архів
3. Відкрийте `chrome://extensions/` (або `edge://extensions/`)
4. Увімкніть **Режим розробника**
5. Натисніть **Завантажити розпаковане розширення**
6. Оберіть папку `calendar-online-helper-nata`

## Використання

1. Клікніть по іконці розширення
2. Дата підставляється автоматично з календаря ПК (сьогодні)
3. Оберіть задачі або введіть свою
4. Натисніть **Додати**

Усі задачі завжди додаються на **цілий день**.

## Пресети за замовчуванням

- Фото журналу
- Алібіба
- Розкадравки П1Ж
- Перші кадри П1Ж
- Зйомка
- Друк постерів
- Оформлення акції
