# Calendar.online Helper

Розширення для Chrome / Edge — швидке додавання задач у Calendar.online **на весь день**.

## Встановлення

1. Завантажте `calendar-online-helper.zip`
2. Розпакуйте архів
3. Відкрийте `chrome://extensions/` (або `edge://extensions/`)
4. Увімкніть **Режим розробника**
5. Натисніть **Завантажити розпаковане розширення**
6. Оберіть папку `calendar-online-helper`

## Використання

1. Клікніть по іконці розширення
2. Перевірте дату (за замовчуванням — сьогодні з ПК)
3. Оберіть людину та задачі
4. Натисніть **Додати**

Усі задачі завжди додаються на **цілий день**.

## Налаштування

Через ⚙ у popup або сторінку налаштувань розширення:

- ID календаря з посилання
- Людина за замовчуванням
- Список пресетів задач
